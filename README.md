# IRIS — Intelligent Screen Habits & Eye Health Monitor

![IRIS Emblem](public/assets/iris-emblem-black.png)

IRIS is an advanced, privacy-first desktop application designed to monitor screen habits, track blink rates and viewing distance in real time, deliver proactive eye fatigue warnings, guide restorative breaks, and provide an interactive real-time voice assistant powered by Google Gemini.

Developed with ❤️ by a team of Class 11 students from **Sharjah Indian School, Juwaiza** (Alvin, Devak, Figo, Jeremi, and Blesson).

---

## 🌟 Key Features

- **Real-Time Vision Monitoring**: Tracks user face position, viewing distance (cm), and blink rate (blinks per minute) using client-side MediaPipe vision tasks without transmitting video data externally.
- **Hands-Free Voice Assistant (RETIS)**: Engage in natural voice conversations about your screen habits, blink stats, and posture. Powered by **Gemini 3.8 Flash TTS** using the energetic, charismatic **"Mako" voice (The Game Show Host preset)**.
- **Simultaneous Text & Voice Streaming**: Instantaneous lockstep streaming where text appears in sync with spoken audio chunks as soon as sentence synthesis completes.
- **Barge-In Interruption Support**: Interrupt the assistant at any time while it is speaking to ask follow-up questions or redirect the conversation.
- **Dynamic Break & Exercise Routines**: Built-in guided eye relaxation exercises, 2-minute posture resets, and blink training routines to combat digital eye strain.
- **Comprehensive Telemetry & Reports**: 30-day session history storage, fatigue scoring, heatmaps, and downloadable monthly PDF reports.
- **Local Fast-Path Fallback**: Deterministic sub-50ms responses for direct single-metric queries.

---

## 🛠️ How It Works

IRIS combines a responsive **React 19 single-page application (SPA)** with an **Express.js backend server** running on Node.js:
1. **Client Vision & Telemetry**: MediaPipe Vision runs locally in the browser to compute blink rate, distance, and face presence.
2. **Server-Side LLM & TTS Pipeline**: The Node.js Express server (`server.ts`) handles API proxying to the `@google/genai` SDK, enforcing strict grounding against live telemetry snapshots.
3. **Low-Latency Audio Streaming**: Server-sent events (SSE) stream text chunks and 24kHz mono PCM WAV audio generated by Gemini 3.8 Flash TTS to eliminate latency.

## 📥 Installation & Downloads

### 1. Pre-built Windows Executable (`.exe`)
You can download the latest pre-compiled Windows executable directly from the [GitHub Releases Page](https://github.com/your-username/iris-screen-habits/releases).
- Simply download `IRIS-Setup.exe` (or the portable `.exe`), double-click to launch, and start monitoring your screen habits immediately.

### 2. Running on Linux via Wine
IRIS is fully compatible with Linux operating systems using **Wine**:
1. Ensure Wine is installed on your Linux distribution (e.g., `sudo apt install wine` or `sudo dnf install wine`).
2. Download the `IRIS.exe` binary from the [Releases Page](https://github.com/your-username/iris-screen-habits/releases).
3. Run the executable via Wine in your terminal:
   ```bash
   wine IRIS.exe
   ```
   *(Note: Ensure your Linux user has webcam permissions enabled for camera-based blink tracking).*

## ⚙️ Building from Source Code

### Prerequisites
- **Node.js** (v18.x or v20.x recommended)
- **npm** (v9+ or bun)
- A valid **Google Gemini API Key** (for AI chat and Mako TTS features).

### Step-by-Step Build Instructions

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/your-username/iris-screen-habits.git
   cd iris-screen-habits
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Copy `.env.example` to `.env` and set your Gemini API key:
   ```bash
   cp .env.example .env
   ```
   Edit `.env` and add your API key:
   ```env
   GEMINI_API_KEY=your_actual_api_key_here
   ```

4. **Run in Development Mode**:
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:3000`.

5. **Build for Production**:
   To bundle the frontend assets and prepare the full-stack server for production deployment:
   ```bash
   npm run build
   ```

6. **Start the Production Server**:
   ```bash
   npm start
   ```
